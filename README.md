# Tulsyan Healthcare – Next.js B2B site
Next.js 14 (App Router) · MongoDB (Mongoose) · Cloudinary · Framer Motion · JWT-cookie admin
1. `npm i`  2. copy `.env.example` → `.env.local` and fill it  3. `npm run seed` (loads 38 catalogue items)  4. `npm run dev`
Admin: `/admin/login` (ADMIN_USER / ADMIN_PASS) → products CRUD with Cloudinary upload, enquiries inbox.
